## 一、仓库说明

本仓库用于存放《嵌入式系统实验》课程的全部实验材料，所有实验统一放在本仓库内，
每个实验一个独立子文件夹，按 `labXX_主题` 命名，不新建其他仓库。

每个实验文件夹统一包含三部分：

| 目录 | 内容 |
| --- | --- |
| `code/` | 完整工程源码（STM32CubeIDE 工程，含 `.ioc` 配置） |
| `report/` | 实验报告 |
| `screenshots/` | 实验现象截图（LED 效果、数码管/LED 显示、调试截图等） |

## 二、实验目录

| 文件夹 | 实验内容 | 状态 |
| --- | --- | --- |
| `lab01_led` | 实验 1：LED 流水灯 | ✅ 已完成 |
| `lab02_matrix_key` | 实验 2：矩阵键盘 | ✅ 已完成 |

> 后续实验：新建 `labXX_主题` 文件夹 → 放入 `code/`、`report/`、`screenshots/` → 更新本表 → 推送。

## 三、开发环境

- 开发板：STM32F407 开发板
- 主控芯片：STM32F407ZET6（Cortex-M4，168 MHz）
- 开发工具：STM32CubeIDE（STM32CubeMX 生成工程）
- 调试器：ST-Link（SWD）
- 工程配置：`*.ioc` 文件可用 STM32CubeMX 打开重新生成代码

## 四、提交规范

- 每完成一个完整实验，执行一次 push 到本公开仓库；
- 开发调试过程允许本地多次 commit，commit 摘要写明实验与进度，例如
  `lab01：完成 GPIO 初始化`、`lab01：实现流水灯效果`；
- 不提交编译中间产物（`.o`、`.d`、`.elf`、`.hex`、`.axf`、`Debug/`、`Release/` 等），
  已在根目录 `.gitignore` 中过滤；
- 文件夹、工程路径全部使用英文，不使用中文、空格。

## 五、实验报告要求

每个实验报告包含：实验目的、实验环境、硬件连接、原理与设计、关键代码、
实验现象、问题与解决、实验总结。
